# 账期助手 · 上架 App Store 与 Google Play 指南（不需要 Mac）

整体思路：同一套代码，用 Capacitor 打包成 iPhone 和安卓 App。用户**免费下载**，在 App 里**用苹果 / 谷歌内购订阅**（两家商店规定 App 内只能用自己的付款）。网页版继续用 Mercado Pago（卡 / PIX）。三边是同一个账号，在哪里买的都通用；服务端会去苹果、谷歌官方接口核实每一笔购买。

打包在 GitHub 的云端机器上完成（iOS 用 macOS 机器），你只需要在网页上点按钮、填密钥。

> 费用：Apple 开发者 US$99/年；Google Play 开发者 US$25（一次）。GitHub 私有仓库每月有免费的 Actions 分钟数，macOS 分钟按 10 倍计算，一次 iOS 打包约 15–25 分钟。

---

## 第 0 步：定一个 App ID（上架后不能改）

格式像 `com.ecoflasky.zhangqi`。两家商店用同一个。代码里默认就是这个；如果要换：GitHub 仓库 → Settings → Secrets and variables → Actions → **Variables** → New variable：`APP_ID` = 你的 ID。

## 第 1 步：注册开发者账号

- **Apple**：developer.apple.com/programs → Enroll。个人用 Apple ID 即可；以公司名义上架需要 D-U-N-S 编号（巴西公司用 CNPJ 申请，免费，约 1–2 周）。商店里显示的「开发者名称」个人账号是你的姓名，公司账号是公司名。
- **Google**：play.google.com/console → 注册（US$25），完成身份验证。**2023 年后新建的个人账号**，正式上线前必须先做「封闭测试」：至少 12 名测试者连续参与 14 天。公司账号没有这个要求。

## 第 2 步：App Store Connect 里建 App 与内购

1. developer.apple.com → Certificates, Identifiers & Profiles → **Identifiers** → `+` → App IDs → App → Bundle ID 选 Explicit，填第 0 步的 App ID（Capabilities 保持默认，In-App Purchase 默认已开）。
2. appstoreconnect.apple.com → App → `+` 新建 App：平台 iOS，名称「账期助手」，主要语言「简体中文」，Bundle ID 选刚才那个，SKU 随意（如 zhangqi）。
3. **协议、税务和银行**（Business）：签「付费 App 协议」，填银行账户和税务信息。不签这个，内购无法测试也无法上线。
4. 建议加入 **App Store 小型企业计划**（年收入 100 万美元以下）：佣金更低（巴西：10% 佣金 + 5% 苹果支付手续费，否则是 21% + 5%）。
5. App → 功能 → **订阅** → 新建订阅群组「账期助手会员」，在群组里建 4 个自动续期订阅（**产品 ID 必须完全一致**）：

   | 参考名称 | 产品 ID | 时长 | 建议价格（巴西） | 群组内等级 |
   |---|---|---|---|---|
   | T2 年付 | `zq.t2.yearly` | 1 年 | R$ 199,00（没有这个价位就选最接近的） | 1（最高） |
   | T2 月付 | `zq.t2.monthly` | 1 个月 | R$ 19,90 | 1 |
   | T1 年付 | `zq.t1.yearly` | 1 年 | R$ 79,90 | 2 |
   | T1 月付 | `zq.t1.monthly` | 1 个月 | R$ 7,99（没有这个价位就选最接近的） | 2 |

   每个订阅都要填：本地化显示名称和描述（中文、葡语）、价格（选「巴西」为基准，其他国家自动换算）、审核截图（用 `store/screenshots` 里的账号页截图）。
6. App → 功能 → **App 内购买项目** → `+` → 消耗型：产品 ID `zq.ai20`，名称「AI 识别加量包 20 次」，价格 R$ 4,90。
7. App → App 信息 → **App Store 服务器通知**：版本选「版本 2」，正式环境和沙盒环境都填：
   `https://<你的项目>.supabase.co/functions/v1/recognize/iap/apple`
   （「一键部署」运行日志的最后会打印准确网址。）

## 第 3 步：苹果的三把密钥 → 填进 GitHub Secrets

GitHub 仓库 → Settings → Secrets and variables → Actions → **Secrets** → New repository secret：

1. **App Store Connect API 密钥**（云端打包、签名、上传 TestFlight 用）：App Store Connect → 用户和访问 → 集成 → App Store Connect API → 团队密钥 → `+`，权限选「App 管理」，下载 `.p8`（只能下载一次）。
   - `APPLE_ISSUER_ID` = 页面上方的 Issuer ID
   - `APP_STORE_CONNECT_KEY_ID` = 密钥 ID
   - `APP_STORE_CONNECT_PRIVATE_KEY` = `.p8` 文件的全部内容（用记事本打开复制，包括 BEGIN/END 两行）
2. **App 内购买项目密钥**（服务端向苹果核实购买用）：同一页面左侧「App 内购买项目」→ `+` → 下载 `.p8`。
   - `APPLE_IAP_KEY_ID` = 密钥 ID
   - `APPLE_IAP_PRIVATE_KEY` = 这个 `.p8` 的全部内容
3. **iOS 证书私钥**：GitHub → Actions → 「生成签名密钥」→ Run workflow。运行完下载产物 `signing-secrets`，把 `IOS_CERTIFICATE_PRIVATE_KEY.pem` 的内容填为 `IOS_CERTIFICATE_PRIVATE_KEY`。（同一个产物里还有安卓的，见第 4 步；填完记得删除产物。）

## 第 4 步：Google Play Console 里建 App 与内购

1. Play Console → 创建应用：名称「账期助手」，默认语言「中文（简体）」，应用，免费。
2. **安卓签名**：用第 3 步下载的 `signing-secrets` 填：
   - `ANDROID_KEYSTORE_BASE64` = `ANDROID_KEYSTORE_BASE64.txt` 的内容
   - `ANDROID_KEYSTORE_PASSWORD` = `ANDROID_KEYSTORE_PASSWORD.txt` 的内容
   - 把 `upload.keystore` 另外备份好。Play 会启用「Play 应用签名」，这把只是上传密钥，丢了可以申请重置。
3. 先运行一次打包（第 6 步，平台选 android），下载产物里的 `app-release.aab`，在 Play Console → 测试 → 内部测试 → 创建版本，**手动上传这第一个 AAB**（Google 要求第一次手动上传，之后才能自动上传）。
4. 获利 → 产品 → **订阅**：
   - 新建订阅 `zq_t1`，加两个基础方案：`monthly`（每月自动续订，R$ 7,99）、`yearly`（每年，R$ 79,90）
   - 新建订阅 `zq_t2`，基础方案 `monthly`（R$ 19,90）、`yearly`（R$ 199,00）
   - 获利 → 产品 → **应用内商品**：`zq_ai20`，R$ 4,90
   - 都要「启用 / 激活」。
5. **服务账号**（服务端核实购买 + 自动上传）：Google Cloud Console（和 Play 关联的项目）→ IAM → 服务账号 → 新建 → 创建 JSON 密钥并下载。在 Play Console → 用户和权限 → 邀请这个服务账号邮箱，权限给「查看财务数据」「管理订单和订阅」，以及「发布到测试轨道」。
   - `GOOGLE_SERVICE_ACCOUNT` = JSON 文件的全部内容
   - `PLAY_UPLOAD_SERVICE_ACCOUNT` = 同一个 JSON（用于自动上传；不填就只打包不上传）
6. **实时开发者通知**（订阅续费、退款能马上同步）：
   - Google Cloud → Pub/Sub → 新建主题 `play-rtdn`，给 `google-play-developer-notifications@system.gserviceaccount.com` 加「Pub/Sub 发布者」角色。
   - 在这个主题下新建「推送」订阅，端点网址：`https://<你的项目>.supabase.co/functions/v1/recognize/iap/google?token=<一串随机字母>`
   - `GOOGLE_RTDN_TOKEN` = 上面那串随机字母
   - Play Console → 获利设置 → 实时开发者通知 → 主题名称填 `projects/<项目ID>/topics/play-rtdn` → 发送测试通知。

## 第 5 步：让服务端用上这些密钥

填完 Secrets 后，GitHub → Actions → **一键部署** → Run workflow。它会把 `APPLE_*`、`GOOGLE_*` 写进 Supabase 识别函数。完成后打开网页版「账号与套餐」，App 里的内购按钮就能用了。

## 第 6 步：打包上传

GitHub → Actions → **打包 App** → Run workflow：
- 平台：both / ios / android
- 版本号：如 `1.0.0`（每次上架新版本时加大）；构建号自动用运行编号递增。

完成后：
- iOS：约 10–30 分钟后出现在 App Store Connect → TestFlight。先自己装 TestFlight 测一遍（用沙盒测试账号测内购：用户和访问 → 沙盒 → 测试员）。
- 安卓：自动上传到「内部测试」（第一次手动，见第 4.3 步）。

## 第 7 步：填写商店页面并提交审核

文案与截图都准备好了：
- 文案：`docs/商店文案.md`（中文、葡语）
- 截图：`store/screenshots/ios-6.9/`（1320×2868，App Store）、`store/screenshots/android/`（1080×2160）、`store/feature-graphic.png`（1024×500）、`store/icon-512.png`
- 隐私政策网址：`https://<你的网站>/legal/privacy.html`；使用条款：`.../legal/terms.html`（App Store 描述最后要附上使用条款链接，或在 App 信息里选「标准 Apple EULA」）。

**App Store 审核要点**
- 审核备注里给一个测试账号（例如 `review@你的域名`，先注册好、保持在试用期内），写明：「登录后可用全部功能；订阅在『设置 → 账号与套餐』，使用沙盒账号测试内购；『删除账号』在同一页底部」。
- App 隐私（数据收集）如实填写：联系信息（邮箱）——用于 App 功能，关联身份，不用于追踪；用户内容（照片、其他用户内容）——用于 App 功能；购买记录——用于 App 功能。不做追踪。
- 年龄分级：4+；类别：财务（主要）/ 商务（次要）。
- 加密：已在 Info.plist 声明只用标准 HTTPS（ITSAppUsesNonExemptEncryption = NO）。

**Google Play 审核要点**
- 数据安全表单：收集邮箱、照片（用于识别，不共享）、购买记录、App 内容；传输加密；用户可请求删除（App 内 + 网址 `.../legal/privacy.html`）。
- 删除账号网址：Play 要求提供网页入口，填隐私政策网址（第 5 节写了删除方法）。
- 目标受众：18 岁以上；内容分级问卷：工具类，无敏感内容。
- 个人开发者账号：先跑 14 天、12 人的封闭测试，再申请正式版。

## 常见问题

- **商店价格和网页价格不一样？** 苹果和谷歌只能选它们的价位表，可能和标价差几分钱。App 里显示的是商店真实价格，网页显示我们自己的标价，账号权益完全一样。
- **用户在网页订阅了，再装 App？** 登录同一个账号即可直接使用，不需要再买。反过来也一样。
- **用户在 App 里怎么取消？** 「账号与套餐 → 管理订阅」打开系统的订阅页。
- **退款？** App 内购买由苹果 / 谷歌处理退款；退款通知到达后服务端会自动收回权益和加量次数。
- **想改 App 图标？** 改 `assets/icon.svg`，在有 Playwright 的电脑上运行 `npm run assets`。
