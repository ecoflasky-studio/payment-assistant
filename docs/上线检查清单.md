# 上线检查清单

按顺序打勾。打 ⚙️ 的是一次性设置，打 🔁 的是每次发版都要做。

## 服务端（Supabase）
- [ ] ⚙️ GitHub Secrets 填好：`SUPABASE_ACCESS_TOKEN`、`SUPABASE_PROJECT_REF`、`GEMINI_API_KEY`、`MP_ACCESS_TOKEN`（网页收款）、`APPLE_*`、`GOOGLE_*`
- [ ] ⚙️ Actions →「一键部署」跑一次，打开网站 `/zq-config.json` 能看到 `url`、`key`、`fn`
- [ ] ⚙️ SMTP 配好（Resend），「忘记密码？」能收到验证码（`上架指南.md` 5b）
- [ ] ⚙️ Authentication → Sign In / Providers → Email：关闭「Confirm email」（密码注册即登录）
- [ ] ⚙️ Authentication → URL Configuration：Site URL 填网站地址
- [ ] ⚙️ Mercado Pago：Webhook 指向 `…/functions/v1/recognize/billing/webhook`，事件勾选「Planos e assinaturas」和「Pagamentos」，用正式凭证（不是测试凭证）
- [ ] ⚙️ App Store Server Notifications V2 → `…/recognize/iap/apple`；Google Play RTDN（Pub/Sub 推送）→ `…/recognize/iap/google?token=<GOOGLE_RTDN_TOKEN>`
- [ ] 🔁 Supabase → Edge Functions → recognize → Logs：部署后没有报错；搜 `[client]` 看有没有新错误

## 网页版
- [ ] 🔁 手机打开网站：注册 → 试用 30 天 → 拍一张单据识别 → 标记已付 → 退出 → 再用密码登录
- [ ] 🔁 网页订阅一次 T1 月付（可用 Mercado Pago 测试账号），确认账号页显示已订阅，再取消
- [ ] 🔁 PIX 年付、AI 加量包各走一遍（测试账号）
- [ ] 🔁 断网刷新：页面仍能打开、能记账；联网后自动同步
- [ ] 🔁 分享网站链接到 WhatsApp：能看到预览图和标题

## App（iOS / Android）
- [ ] ⚙️ App ID、内购商品 ID 与 `shared/plans.mjs` 的 `STORE` 一致；价格档位 R$ 7,99 / 79,90 / 19,90 / 199,00 / 4,90（与 `PLANS`、`AI_PACK` 相同）
- [ ] ⚙️ 订阅群组里 T2 等级高于 T1；年付写明「送 2 个月」
- [ ] 🔁 Actions →「打包 App」，填版本号（如 1.0.0）；构建号自动递增
- [ ] 🔁 TestFlight / 内部测试：沙盒账号买 T1 月付 → 账号页显示 App Store / Google Play 来源 → 恢复购买 → 管理订阅
- [ ] 🔁 App 里看不到 Mercado Pago、PIX 字样（苹果规则 3.1.1）
- [ ] 🔁 面容 ID / 指纹解锁、到期本地通知（把一笔账单到期日改成明天）
- [ ] 🔁 「删除账号」能删掉，并提示去商店取消订阅
- [ ] 🔁 设置页底部的版本号和商店里填的一致
- [ ] ⚙️ 商店页：截图（`store/screenshots/<语言>/`）、文案（`docs/商店文案.md`）、栏位清单（`docs/上架上传清单.md`）、隐私政策和使用条款网址、审核用测试账号

## 数据与隐私
- [ ] ⚙️ 隐私政策里的联系邮箱能收信
- [ ] ⚙️ App Store「App 隐私」问卷：邮箱（账号）、购买记录、用户内容（账单、照片，用于 App 功能）、诊断（匿名错误报告，不关联身份）；不追踪
- [ ] ⚙️ Google Play「数据安全」表单同上；数据传输加密、用户可删除账号
- [ ] 🔁 仓库里没有真实票据和密钥（`git grep -i "api_key\|secret"` 只出现变量名）

## 出问题时
- 识别失败：Logs 里搜 `recognize`；常见是 Gemini 额度用完（换模型或等次日）
- 订阅没生效：账号页点「恢复购买」；Logs 搜 `[iap]` 或 `[saas]`
- 用户报错：请对方发「设置」页最下方的版本号，再到 Logs 搜 `[client]` 和版本号
