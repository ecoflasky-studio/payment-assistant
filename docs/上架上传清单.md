## 一、App Store Connect

### 1. App 信息（App Information）
| 栏位 | 填什么 |
|---|---|
| 主要语言 | 简体中文 |
| 本地化 | 加「葡萄牙语（巴西）」「英语（美国）」，每种语言填名称和副标题（见《商店文案》） |
| 类别 | 主要：财务；次要：商务 |
| 内容版权 | 不包含第三方内容 |
| 年龄分级 | 问卷全部选「无」，结果 4+ |
| 许可协议 | 标准 Apple EULA（描述末尾已附使用条款链接） |

### 2. 价格与销售范围
- 价格：免费
- 销售范围：建议先只选**巴西**（也可以全选，App 支持英文）

### 3. App 隐私（App Privacy）
隐私政策网址：`https://zqzh.com.br/legal/privacy.html`

「是否收集数据」选**是**，然后勾选：

| 数据类型 | 用途 | 关联身份 | 用于追踪 |
|---|---|---|---|
| 联系信息 → 电子邮件地址 | App 功能 | 是 | 否 |
| 用户内容 → 照片或视频 | App 功能 | 是 | 否 |
| 用户内容 → 其他用户内容（账单、备注） | App 功能 | 是 | 否 |
| 购买项目 → 购买历史 | App 功能 | 是 | 否 |
| 标识符 → 用户 ID | App 功能 | 是 | 否 |
| 诊断 → 崩溃数据 / 其他诊断数据（匿名错误报告） | App 功能 | 否 | 否 |

「追踪」：不追踪用户。

### 4. 版本页面（1.0 准备提交）
每种语言（左上角切换语言）都要填：
- **截图**：6.9 英寸 iPhone 上传 `store/screenshots/<语言>/ios-6.9/` 的 6 张（1320×2868），按 1→6 顺序。其他尺寸会自动缩放，不用另传。
- **推广文本、描述、关键词**：见《商店文案》
- **技术支持网址**：`https://zqzh.com.br`
- **营销网址**（可空）：`https://zqzh.com.br`

只填一次：
- **构建版本**：选 GitHub Actions「打包 App」上传的那个版本（TestFlight 里显示「可供测试」后才能选）
- **App 内购买项目和订阅**：勾选 4 个订阅 + 1 个加量包，和这个版本一起提交审核
- **版权**：`2026 EcoFlasky`（公司账号填公司名）
- **App 审核信息**：联系人姓名、电话、邮箱；**登录信息**填审核测试账号；**备注**贴《商店文案》末尾的英文审核备注
- **版本发布**：建议选「手动发布」，审核通过后自己点发布

## 二、Google Play Console

### 1. 主要商店详情（每种语言一套）
| 栏位 | 素材 |
|---|---|
| 应用名称 / 简短说明 / 完整说明 | 《商店文案》Google Play 表格 |
| 应用图标（512×512） | `store/icon-512.png` |
| 置顶大图（1024×500） | `store/feature-graphic-<语言>.png` |
| 手机截图（至少 2 张，最多 8 张） | `store/screenshots/<语言>/android/` 的 6 张（1080×2160） |
| 7 英寸 / 10 英寸平板截图 | 可不填 |

### 2. 应用内容（App content，每项点进去答问卷）
| 项目 | 怎么答 |
|---|---|
| 隐私权政策 | `https://zqzh.com.br/legal/privacy.html` |
| 广告 | 不包含广告 |
| 应用访问权限 | 「部分功能受限」→ 添加审核账号邮箱和密码，说明「登录后可使用全部功能」 |
| 内容分级 | 类别选「实用工具 / 效率」，所有问题选「否」 |
| 目标受众 | 18 岁及以上；不吸引儿童 |
| 新闻应用 | 否 |
| 新冠应用 | 否 |
| 数据安全 | 见下一节 |
| 政府应用 | 否 |
| 金融功能 | 选「我的应用不提供上述任何金融功能」（我们只记录账单，不经手资金） |
| 健康 | 否 |

### 3. 数据安全（Data safety）
- 是否收集或分享用户数据：**是**
- 传输时是否加密：**是**
- 用户能否请求删除数据：**是**（App 内「删除账号」，网址 `https://zqzh.com.br/legal/privacy.html`）

| 数据类型 | 收集 | 分享 | 必需/可选 | 用途 |
|---|---|---|---|---|
| 个人信息 → 电子邮件地址 | 是 | 否 | 必需 | 账号管理、App 功能 |
| 照片和视频 → 照片 | 是 | 否 | 可选 | App 功能（识别单据） |
| 财务信息 → 购买记录 | 是 | 否 | 必需 | App 功能、账号管理 |
| 财务信息 → 其他财务信息（账单金额、到期日） | 是 | 否 | 必需 | App 功能 |
| 应用活动 → 其他用户生成的内容（备注、标签） | 是 | 否 | 可选 | App 功能 |
| 应用信息和性能 → 崩溃日志 / 诊断 | 是 | 否 | 可选 | 分析（修复问题） |

> 「分享」指交给第三方自己使用；交给 Supabase、Google Gemini 这类代我们处理的服务商不算分享。

### 4. 发布
- **测试 → 内部测试**：第一次手动上传 `app-release.aab`，之后 GitHub Actions 自动上传
- 公司账号**不需要** 12 人 14 天封闭测试，内部测试没问题后可直接建「正式版」
- 正式版 → 国家/地区：巴西（或全部）→ 审核
